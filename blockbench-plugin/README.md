# ATM & Kiosk OBJ Helper for Blockbench

A small Blockbench plugin for the ATM/kiosk OBJ workspace. It adds a shortcut under File → Import with the basic import instructions.

## Load into Blockbench
1. Download `atm_kiosk_obj_helper.js` from this folder.
2. In Blockbench, open **File → Plugins**.
3. Choose **Load Plugin from File** and select the downloaded JavaScript file.
4. Use **File → Import → Import ATM / Kiosk OBJ (Help)** for the reminder.
5. To actually display the model, use **File → Import → Import OBJ Model** and select `ATM.obj` or `kios jualan.obj`.

This helper does not manufacture textures or convert OBJ geometry into Minecraft cube elements. Keep the source OBJ, MTL, and texture images together when available.
